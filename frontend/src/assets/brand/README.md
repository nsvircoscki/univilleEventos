# Marca Univille

Arquivos oficiais obtidos em https://www.cmarcauniville.com/downloads (Logo — Univille).

- `univille-horizontal.png`: marca mãe horizontal original.
- `univille-horizontal-branca.png`: versão negativa oficial para fundos verdes.

Os PNGs preservam a composição e as proporções fornecidas pela instituição. Não aplicar filtros, recortar o símbolo, alterar cores ou separar o lettering. A área transparente original é preservada.

Paleta RGB consultada em https://www.cmarcauniville.com/exp-cores:

| Cor | RGB | Hexadecimal |
| --- | --- | --- |
| Verde escuro | 0, 95, 54 | #005F36 |
| Verde claro | 130, 197, 91 | #82C55B |
| Branco | 255, 255, 255 | #FFFFFF |
| Areia | 227, 225, 218 | #E3E1DA |

A fonte existente da aplicação foi mantida por solicitação. As cores auxiliares de texto, bordas, estados e erros são cores funcionais da interface, não variações do logo.
