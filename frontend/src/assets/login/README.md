# Referência visual do login

Layout adaptado de https://univilleeduca.univille.br/FrameHTML/web/app/edu/PortalEducacional/login/ a pedido do usuário.

Imagem de fundo e logo obtidos dos arquivos públicos `assets/img/bg.jpg` e `assets/img/logo-responsivo.png` do portal. Arquivos mantidos localmente para evitar dependência do portal em tempo de execução.

Título adaptado para Agenda de eventos, mantendo fonte e autenticação próprias da aplicação. Recuperação de senha orienta a procurar a administração da agenda.
